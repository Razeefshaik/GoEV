Quick guide

How to use the GoEV dashboard

Run a simple simulation in four steps, then read what the results mean. No technical background needed.

What is this?

GoEV simulates a small electricity network (28 connection points, called buses) that does not get enough power from the main grid. Electric vehicles (EVs) drive to charging stations and send some of their battery energy back into the network. This is called Vehicle-to-Grid (V2G). The dashboard shows how much this helps.

Opening the dashboard

Open the dashboard here: goev-backend.onrender.com

The server is on free hosting and sleeps when nobody uses it. The first visit can take up to one minute. Grey moving placeholders and a loading message are shown while it wakes up. Please wait; there is no need to refresh.

Run a simple simulation (4 steps)

  1. Leave Experiment and Assignment policy as they are. The defaults are a good first example.
  2. Click the green Start new run button.
  3. Click Play simulation. Time moves forward by itself and the EVs start driving. Click it again to pause.
  4. Scroll down to watch the results update. To jump straight to the final result, click Run to end.

To start over at any time, click Start new run again.

Every option in one line

Experiment (ready-made situations to test)

moderate shortage Default. The grid gives too little power, so EV help is useful.
no shortage The grid has plenty of power. EVs are not really needed.
weak voltage A weaker, lower-voltage network where voltage becomes the main problem.
multiple stations EVs are spread over several charging stations.
energy depletion EVs have small batteries, so their help runs out quickly.
unwilling EV owners do not agree to share energy, so EVs give no help.
incompatible Station plugs do not match the EVs, so EVs cannot connect.
site bottleneck Stations can pass only a little power, which limits EV help.
travel reserve EV batteries are almost at their safe minimum, so there is little to give.
departure EVs must leave early, so they help only for a short time.
stale telemetry Station status data is out of date, so stations are not trusted.
excess injection EVs could push too much power; shows the system stopping unsafe overload.
insufficient support Demand is much higher; EVs help but cannot close the whole gap.

Assignment policy (how EVs are sent to stations)

Coordinated heuristic Default. Sends each EV to the station where it helps the network most.
Nearest eligible Sends each EV to the closest suitable station.
Without V2G EVs give no energy. Useful to see the network on its own.

Buttons and settings

Start new run Starts a fresh simulation with the chosen experiment and policy.
Time step How much simulated time passes per step: 1, 5 or 15 minutes.
Play simulation Moves time forward automatically. Click again to pause.
Step → Moves forward by exactly one time step.
Run to end Jumps straight to the end of the simulation.
Keep simulated stations online Leave ticked. Unticking pretends stations went silent, which stops EV help.
Export run Downloads the results of the current run as a file.
Customize fleet & stations Add or edit your own EVs and stations, then start a new run with them.
Motion on / off Turns the moving-vehicle animation on or off.
Presentation view Hides the side menu and keeps the controls at the top. Good for a projector.
Electrical view / Geographic map Shows the network as a diagram or on a real map.
Colour buses by Colours the buses by voltage, unserved demand or EV support.
Fit network Re-centres the network picture.
Compare all 3 policies (Further down the page) runs all three policies on the same situation side by side.

Reading the results

1. Summary cards (top of the page)

  • Demand supplied: power actually reaching homes. Higher is better.
  • Supply gap: power homes wanted but did not get. Lower is better.
  • EV contribution: power the parked EVs are giving to the network.
  • Lowest voltage: must stay above the allowed minimum (0.95) for the network to be safe.

2. Network picture ("Your neighbourhood, connected")

  • Each circle is a bus. Bus 1 (left) is where power comes from the main grid.
  • Orange icons (V2G-1, V2G-2, ...) are charging stations. The small cars are EVs.
  • Click anything to see its details on the right.

3. EV fleet ("Every EV has a journey")

  • Battery charge (SOC): how full the battery is.
  • Each EV keeps a 20% owner reserve, so it always has enough charge to continue its trip.
  • Supplying now: how much power this EV is giving to the network.

4. The main result ("See the difference EVs make")

  • Grey bar = the same network without EV help. Green bar = with EV help.
  • A longer green bar means EVs helped supply more energy to homes.
  • The other charts below it show more detail. Hover over a point to see its value.

Small glossary

kWPower at this moment (like speed).
kWhEnergy over time (like distance travelled).
SOCState of charge: battery level in %.
puVoltage compared with normal. 1.00 = normal, below 0.95 = too low.
V2GVehicle-to-Grid: an EV sending battery energy back to the network.

This is a software simulation. Vehicle routes and map positions are generated for demonstration and are not real roads.
